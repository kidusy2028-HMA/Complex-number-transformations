1. Project Overview

Introduction

Complex numbers are widely used in mathematics, physics, engineering, and computer graphics.

In two-dimensional computer graphics, every point can be represented by a complex number. Multiplication and addition can then be used to rotate, scale, and translate objects.

Research Question

How can complex-number multiplication and addition be used to perform geometric transformations on images and two-dimensional objects?

Objectives

  • Represent points as complex numbers.
  • Rotate objects using Euler's formula.
  • Scale objects using complex multiplication.
  • Translate objects using complex addition.
  • Combine transformations mathematically.
  • Visualize transformations interactively.

3. Mathematical Explanation

3.1 Complex Representation

Every point (x, y) on the plane can be represented as:

z = x + iy

The real component represents the horizontal coordinate. The imaginary component represents the vertical coordinate.

3.2 Rotation

To rotate a point counterclockwise by angle θ:

z' = z(cos θ + i sin θ)

Using Euler's formula:

e^(iθ) = cos θ + i sin θ

Therefore:

z' = ze^(iθ)

3.3 Scaling

Multiplication by a positive real number r changes the distance from the origin.

z' = rz

For example, r = 2 doubles the size, while r = 0.5 reduces it by half.

3.4 Translation

Adding a complex number moves a point horizontally and vertically.

z' = z + (a + bi)

3.5 Combined Transformation

z' = r(cos θ + i sin θ)z + (a + bi)

This is the main mathematical equation used by the simulator.

3.6 Cartesian Form

Substituting z = x + iy gives:

x' = r(x cos θ − y sin θ) + a
y' = r(x sin θ + y cos θ) + b

These equations determine the new position of each point after the transformation.

4. Mathematical Experiments

Experiment 1: Rotation by 90°

z = 3 + 4i
z' = i(3 + 4i) = −4 + 3i

Experiment 2: Scaling

z' = 2(3 + 4i) = 6 + 8i

Experiment 3: Translation

z' = (3 + 4i) + (2 + 3i) = 5 + 7i

Experiment 4: Combined Transformation

z' = 2i(3 + 4i) + (1 + 2i)
z' = −7 + 8i

6. Results and Conclusion

Key Findings

Complex multiplication can simultaneously rotate and scale points on a two-dimensional plane.

Complex addition translates points without changing their shape or orientation.

By combining these operations, an object can be transformed using a single expression:

z' = r e^(iθ)z + (a + bi)

Real-World Applications

  • Computer graphics
  • Image processing
  • Two-dimensional animation
  • Geometric modeling
  • Robotics

Limitations

  • The simulator operates in two dimensions.
  • Scaling is uniform in every direction.
  • Objects rotate around their local center.
  • Parts extending outside the canvas are clipped.
  • The website uses JavaScript for live transformations, not Python execution.

Conclusion

This project demonstrates how complex-number operations can be used to perform real geometric transformations on images and shapes.

The interactive laboratory connects algebraic calculations with their geometric effects, making complex numbers easier to visualize.
